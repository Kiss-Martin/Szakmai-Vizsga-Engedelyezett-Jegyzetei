Gyors Linq
  • Where(x => ...) → szűrés
  • Select(x => ...) → átalakítás
  • SelectMany(...) → lapítás (lista a listából)
  • OrderBy(x => ...) → növekvő rendezés
  • OrderByDescending(...) → csökkenő
  • GroupBy(x => ...) → csoportosítás kulcs szerint
  • ToList() → listává alakít
  • ToArray() → tömbbé alakít
  • First() → első elem (hiba ha nincs)
  • FirstOrDefault() → első vagy null/default
  • Single() → pontosan 1 elem kell
  • SingleOrDefault() → 0 vagy 1 elem
  • Count() → elemszám
  • Sum(x => ...) → összeg
  • Max() / Min() → legnagyobb / legkisebb
  • Average() → átlag
  • Distinct() → duplikátumok eltávolítása
  • Skip(n) → első n kihagyása
  • Zip(a, b, (x,y)=>...) → párosítás két lista között
  • Join(...) → összekapcsolás kulcs alapján

globalStore.ts kiinduló

import { create } from "zustand";

type GlobalStateData = {
  globalVariable?: string;
};

type GlobalStore = {
  gs: GlobalStateData;
  set: <K extends keyof GlobalStateData>(key: K, value: GlobalStateData[K]) => void;
};

export const useGlobalStore = create<GlobalStore>()((set) => ({
  gs: {
    globalVariable: "valami"
  },

  set: (key, value) =>
    set((state) => ({
      gs: {
        ...state.gs,
        [key]: value,
      },
    })),
}));

globalStore használata example

const { gs, set } = useGlobalStore();
set("globalVariable", "valami más");

Ez egy globális változó (bármelyik komponensben elérhető változó) értékét frissíti, gyakorlati haszna pl. UI state, light/dark mode, keresési paraméter

GET - Listázás és Szűrés 
        // Route("api") miatt ez ilyen lesz:
        // <ipcím>/api/konyvek/{orszagNev}/lista
        
        [HttpGet("konyvek/{orszagNev}/lista")]
        public IActionResult GetKonyvek([FromRoute] string orszagNev, [FromQuery] int? minOldalszam)
        {
            var query = dbContext.Set<Konyv>()
                                 .Include(k => k.Szerzo)
                                 // A ThenInclude arra való, hogy a már behozott (Include-olt) tábla egy további kapcsolódó al-tábláját is hozzáfűzzük a lekérdezéshez. Itt a Könyvhöz bekértük a Szerzőt, majd a Szerzőhöz a hazáját (Ország).
                                 .ThenInclude(sz => sz.Orszag)
                                 .Where(k => k.Szerzo.Orszag.Nev.ToLower() == orszagNev.ToLower());

            if (minOldalszam.HasValue)
            {
                query = query.Where(k => k.Oldalszam >= minOldalszam.Value);
            }

            var eredmeny = query.Select(k => new
            {
                k.Cim,
                k.Oldalszam,
                Szerzo = k.Szerzo.Nev,
                Orszag = k.Szerzo.Orszag.Nev
            });

            if (eredmeny.Count() == 0)
            {
                return NotFound(new { Message = "Nincs találat...." });
            }

            return Ok(eredmeny);
        }

        [HttpPost("konyvek")]
        public IActionResult CreateKonyv([FromBody] dynamic body)
        {
            try
            {
                Konyv model = JsonSerializer.Deserialize<Konyv>(body.ToString());

                if (model.Oldalszam < 1)
                {
                    return BadRequest(new { Message = "Hibás oldalszám" });
                }

                dbContext.Set<Konyv>().Add(model);
                dbContext.SaveChanges();

                return StatusCode(201, model);
            }
            catch
            {
                return StatusCode(400, new { Message = "Hiba van..." });
            }
        }
PUT - Meglévő Elem Módosítása 
        [HttpPut("konyvek/{id}")]
        public IActionResult UpdateKonyv([FromRoute] string id, [FromBody] dynamic body)
        {
            try
            {
                Konyv? itemToUpdate = dbContext.Set<Konyv>().SingleOrDefault(k => k.Id.ToString() == id);

                if (itemToUpdate == null)
                {
                    return BadRequest(new { Message = "Ilyen könyv nincs..." });
                }

                Konyv model = JsonSerializer.Deserialize<Konyv>(body.ToString());

                if (model.Oldalszam < 1)
                {
                    return BadRequest(new { Message = "Túl rövid..." });
                }

                itemToUpdate.Cim = model.Cim;
                itemToUpdate.Oldalszam = model.Oldalszam;
                itemToUpdate.SzerzoId = model.SzerzoId;

                dbContext.Update(itemToUpdate);
                dbContext.SaveChanges();

                return Ok(itemToUpdate);
            }
            catch
            {
                return StatusCode(400, new { Message = "Hiba van..." });
            }
        }
DELETE - Elem Törlése

export async function GET(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  try {
    const { id } = await params;
    const data = await prisma.table.findUnique({

  } catch (error) {
    return NextResponse.json(
      { message: error instanceof Error ? error.message : "Ismeretlen hiba!" },

where - itt adsz meg feltételeket pl. id: 1 vagy name: "John"

data - itt adod meg a létrehozandó vagy módosítandó adatokat pl. name: "Anna"

select - megadod, hogy mely mezőket akarod visszakapni pl. { id: true, name: true }

include - kapcsolt (relációs) adatokat kérsz le pl. { posts: true }

omit - megadod, mit NE adjon vissza pl. { password: true }

orderBy - rendezés pl. { createdAt: "desc" }

take - hány rekordot kérsz le (limit) pl. 10

skip - hány rekordot hagyjon ki (offset) pl. 5

distinct - csak egyedi értékeket ad vissza pl. ["email"]

create - új kapcsolt rekord létrehozása relációban

update - kapcsolt rekord frissítése

upsert - ha létezik frissít, ha nem, létrehoz

delete - rekord törlése

deleteMany - több rekord törlése feltétel alapján

updateMany - több rekord frissítése feltétel alapján

createMany - több rekord létrehozása egyszerre

count - megszámolja a rekordokat
